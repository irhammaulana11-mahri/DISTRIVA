# Serah terima frontend — gudang ERP, pemetaan SKU↔KHS, sinkronisasi stok, outbox material, dashboard (docs/62 §39–41)
Backend siap di kode (tes lulus); migrasi 160000 (diubah) dan 210000 belum diterapkan ke `distriva_db`. Kontrak: docs/57.
## 1. Gudang dan stok (Master Data)
- **Impor gudang ERP**: tombol "Impor daftar gudang ERP" (tempel/unggah JSON `{gudang:{data:[…]}}`), dry run → tabel (plant, storage location, nama, kode unit, jenis GI/GO, BARU/PERBARUI/DITOLAK) → terapkan. Daftar gudang menampilkan plant, storage location, jenis, kode unit ERP.
- **Impor stok**: terima `.xlsx` ERP "Monitoring Stock" (selain CSV); hasil: total SKU, terpetakan, belum terpetakan, jumlah baris KHS, label gudang; tautan "SKU belum dipetakan" (`/stock-snapshots/{id}/unmapped`, dengan pencarian). Tampilkan tanggal cuplikan dan jumlah SKU terpetakan per cuplikan.
- **Sinkronisasi otomatis**: tab "Riwayat sinkronisasi" (`GET /stock-sync-runs`): status OK/FAILED/SKIPPED berwarna, pesan, waktu, tautan ke cuplikan; spanduk bila `sync_configured=false` ("sinkronisasi belum dikonfigurasi di server"). Tidak ada kolom/ikon yang menampilkan token.
**Tarik stok sekarang (docs/62 §42; pembaruan 13 Nov 2026: dialog kini juga menawarkan "Gunakan token tersimpan" dan centang "Simpan token ini", docs/82 §19.15):** tombol "Tarik stok dari MIMS" (hanya `stock.import`) membuka dialog dengan **kolom token (jenis password, tidak diisi otomatis, tidak disimpan di state global, localStorage, atau URL; dikosongkan setelah dikirim)** dan petunjuk singkat "salin token sesi MIMS Anda dari aplikasi MIMS"; pilihan gudang (bawaan semua) dan tanggal opsional; kirim ke `POST /master-data/stock-sync`; tampilkan hasil per gudang (OK/GAGAL/DILEWATI, pesan, SKU terpetakan). Pesan "token ditolak atau kedaluwarsa" diarahkan ke "ambil token baru dari MIMS". Jangan pernah mencatat token ke konsol atau analitik.
## 2. Meja kerja pemetaan SKU↔KHS (Master Data → Pemetaan Material)
Dua panel: **KHS yang perlu dipetakan** (`/khs-material-map/workbench`, bawaan filter "belum dipetakan" dan urut "dipakai BOM dulu", kolom kode, uraian, satuan, penanda "dipakai BOM", SKU terpetakan) dan, saat satu KHS dipilih, **saran SKU** (`/suggestions?khs_code=`: nomor material, nama ERP, satuan, skor, sumber) dengan tombol **Pilih** (`POST /khs-material-map`; 409 bila SKU sudah dipetakan ke KHS lain) dan kolom cari bebas SKU/nama. Tampilkan **cakupan** (`/coverage`): persen KHS terpakai yang sudah dipetakan dan SKU terpetakan per cuplikan. Tombol impor CSV (`kode_khs,no_material`), hapus pemetaan. Peringatan: saran hanyalah usulan — pengguna wajib memeriksa sebelum memilih. Hanya pemegang `khs.manage` yang melihat tombol ubah.
## 3. Permintaan material (outbox) — menu SPK/WO atau Master Data
Daftar (`/material-requests`) dengan filter status dan "perlu tindak lanjut"; detail: WO, pelanggan, tabel material (KHS, uraian, satuan, jumlah, no. material ERP, alokasi gudang), tiang (KR, TM/TR), **daftar KHS belum terpetakan** (peringatan), riwayat. Tombol (hanya `material_requests.manage`): **Ekspor** (CSV/XLSX/JSON; status → EXPORTED), **Tandai terkirim** (referensi wajib), **Batalkan** (alasan). Status SENT dengan `needs_followup` tampil sebagai peringatan merah.
## 4. Dashboard dan laporan (menu Laporan; modul `reporting` menjadi ACTIVE)
Halaman **Ringkasan** (`/reports/overview`): filter periode (dari/sampai) dan ULP; kartu KPI dan tabel (permohonan per status/jenis/sumber, usulan, survey, MTO, RAB nilai total, KKF layak/tidak layak/diperpanjang, WO, BASTP, permintaan material), tombol Unduh XLSX. Halaman **Alur per ULP** (`/reports/pipeline`): tabel funnel per ULP. Pada versi RKM: tab **Laporan** dengan `per-ulp`, `comparison` (usulan vs validasi vs disetujui), `critical` (material kritis), masing-masing dengan unduhan XLSX. Semua tampil menurut `can['reports.view']` / `can['rkm.view']` dari `/planning/access`.
## 5. Aturan UI dan tes
Fail-closed menurut respons server; pesan 403/404/409/422 apa adanya; jangan pernah menampilkan atau menyimpan token MIMS di klien. Tes Vitest: impor gudang dry-run→terapkan, hasil impor xlsx (terpetakan/tidak), meja pemetaan (pilih saran, 409), riwayat sinkronisasi, outbox (ekspor, tandai terkirim, tindak lanjut), dashboard dengan filter, laporan RKM.
